# Face-embeddings closed-set study

## What this project does

This small educational project demonstrates a closed-set face-recognition style experiment using synthetic, consent-like embeddings. It explains verification versus identification, offers an unknown-person path, and reports simple rates: top-1 identification accuracy, false-match rate (FMR) and false-non-match rate (FNMR). The code uses small synthetic embeddings that mimic per-person variation across two sessions. This is a classroom prototype only — it is deliberately local, small and non-operational and must not be used for any real identity decision.

## Data

The dataset is synthetic: we simulate 12 identities (classes). For each identity we create multiple embedding vectors (128-d) by sampling from a Gaussian centred on a per-identity prototype. A second session for each identity is generated by shifting prototypes slightly to simulate temporal variation. We also generate truly unknown embeddings (not belonging to any enrolled identity) to exercise the unknown-person path. This is a pedagogic stand-in for image embeddings; no photographs are used.

## How to build it

1. Create a Python 3.11+ virtual environment and activate it.
2. Install dependencies with: pip install -r requirements.txt
3. Run the study with: python project.py
4. Run tests with: pytest -q

## How to run

Run python project.py. The script prints a JSON dictionary of metrics for a single deterministic run. To reproduce, call run(seed=42) from Python.

## How to test

Run pytest. Tests check: the function returns the expected metric keys, metric ranges are sensible, a conservative floor for the held-out top-1 accuracy is met, and the main metric is deterministic for the same seed.

## Limitations

This project uses synthetic embeddings, not face photographs or real consented face data. The simulated embeddings are simplified: they omit many real-world effects (lighting, pose, occlusion, demographic variation, sensor differences, adversarial spoofing). The experiment is educational and not suitable for deployment, surveillance, access control or forensic use. Numerical results here do not generalise to real face-recognition systems.

## Next steps

Possible extensions: replace synthetic embeddings with instructor-provided, ethically consented embeddings; compare different embedding sizes or distance metrics; introduce more realistic session noise; and add calibration experiments for thresholds. All extensions must respect explicit consent, data minimisation and strong review before any operational use.
