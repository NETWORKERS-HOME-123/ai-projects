# Networkers Home AI Projects

[![tests](https://github.com/NETWORKERS-HOME-123/ai-projects/actions/workflows/test.yml/badge.svg)](https://github.com/NETWORKERS-HOME-123/ai-projects/actions/workflows/test.yml)

**100 beginner machine learning projects with runnable Python code, tests and honest case studies**, built by [Networkers Home](https://www.networkershome.com) in Bangalore for final year CSE and engineering students.

Every folder has:

- `project.py` — a small, deterministic implementation on a built-in or synthetic dataset (no downloads, no API keys)
- `test_project.py` — pytest checks on the outputs and a metric floor on a held-out split
- `README.md` — what it does, how to build and test it, the measured results, and what it does **not** do

Each project also has a full case study page on networkershome.com with build steps, evaluation checks and a proposed next step: see the index at [https://www.networkershome.com/ai-projects-courses/projects/](https://www.networkershome.com/ai-projects-courses/projects/).

## Run any project

```bash
pip install -r requirements.txt
cd projects/0042-movie-review-sentiment
python project.py          # prints the metrics as JSON
python -m pytest -q        # runs the tests
```
